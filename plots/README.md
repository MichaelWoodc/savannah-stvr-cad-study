# Individual plot collection

Every chart is a separate PNG and SVG, with matching data CSVs. There are no subplot sheets. All call charts use citizen initiation only, with patrol, crime-hot-spot, traffic/subject-stop, park/walk/talk and community-engagement dispatch labels excluded. Original raw logs and audit records are preserved outside this collection. `manifest.csv` lists all image files.

`current_direct__` exports the current address and occupancy cohorts across all five size options and exact/minimum-size groups. Owner/non-owner permit types remain separate lines on each chart; initiation is never split. These presets use 59% booking occupancy and no amenity or above-average filter. `original_size__`, `occupancy_plots__`, `occupancy_plots_commercial_excluded__`, `neighborhood__` and `saved_direct__` reproduce the earlier analysis families using citizen-only records and their stated periods/denominators.

Current full span: January 1, 2024-October 16, 2026. Parking uses the supported January 1-September 20, 2024 period and is marked with *. Earlier snapshots retain their own labeled periods. A reference parcel map, if present, is not a call-rate chart. Arbitrary browser filter combinations were not recorded as historical artifacts.
