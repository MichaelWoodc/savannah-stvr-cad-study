# Final forest plot

This is a forest plot of adjusted call-rate ratios with spatially clustered 95% confidence intervals.

The prior chart mixed curated amenity indicators with alternate keyword extractions. Hot tub / Jacuzzi already combined those terms; the separate Hot Tub keyword row duplicated that concept with a different extraction rule and property count. This final chart retains the combined Hot tub / Jacuzzi indicator. The duplicate swimming-pool extraction is also removed, and wedding/bachelorette rows use the affirmative event-marketing indicators rather than broad mentions. Estimates are selected from the existing models, not averaged or refitted; q values retain the original search correction. The paired CSV contains exactly the plotted rows. removed_alternate_indicators.csv records removed rows. Original analysis exports remain available for audit.
