Methods & downloads
Notes

Neighbor = a shared boundary longer than 0.1 m, with no overlapping interiors. Corner contacts, across-road proximity, and neighbors of neighbors are excluded. Each Call Number is counted once within each house-neighbor cluster.

Annual mean = sum of each parcel clusters neighborhood calls % stvr parcel count % exposure years. Both cohorts use residential neighbors only, and the cohorts overlap. Overlapping clusters can reuse the same call.

Only definitive exact address to parcel matches are used for the statistics. Unmatched calls are excluded. The local license inventory is a snapshot and license status during each call is not established.

The neighbor-only numerator excludes the licensed short term vacation rental parcel entirely. A caller's address or reporting location does not establish where an event originated, or that it was caused by a STVR. The comparison is descriptive; random controls are not matched on neighborhood or building size.
